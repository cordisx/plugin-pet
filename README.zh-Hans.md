# pet

实验中的 CordisX 官方插件候选，通过两个公开受控点位呈现真实 OneWorks Avatar。原生输入框
保留按钮、实际操作、键盘和无障碍语义。

当前选择内置白猫头（`cat` 预设、`white` 配色），保留猫耳和两条圆角长条眼睛，没有嘴巴，
保留模型原配色。主操作位和覆盖层均在单独授权后
接收归一化指针位置；移出窗口保留朝向，重新进入时平滑跟随。插件不接收输入正文，视觉默认点击穿透。
上方猫头选择 v2 状态快照，接收录音与转写状态；左侧听写按钮
保持原样，插件不会接收音频或转写正文。

```sh
npm install
npm run check
npm run dev
```

当前 `cordisx` 依赖指向实验 Host 工作树，尚不是正式兼容版本。远端仓库准入和
许可证待确认；包保持 private，尚未发布。

Avatar 组件使用精确版本 `@oneworks/avatar` / `@oneworks/avatar-react` 1.0.0-rc.8，
组件模块仅导出组件。入口在点位已授权且可用后才通过
`defineReactVisual(Component, { kind: 'react-dom-v1' })` 加载组件。生产构建使用 `cordisx/vite`，完整 ESM 图由
`dist/runtime/artifact.json` 索引，没有自建热更新协议，未挂载编辑器界面。

Avatar 编辑器留待后续；上方猫头通过 Host 提供的受控命中区域接收拖拽与点击。未知原生操作回退到原生视觉；交互授权
仅在当前插件代次有效，可独立撤销。

后续插件可参考 Host 的[视觉设计建议](https://github.com/cordisx/cordisx/blob/codex/composer-animal-visual/.agents/docs/composer-visuals.md#recommended-visual-defaults)，这是推荐默认值，不是强制校验标准。

Launcher 确认的本地开发预览会在本次会话内自动授权已声明的视觉渲染和指针观察，
不再重复弹窗。安装的插件仍保留权限审核；这不授予麦克风权限。

原 SVG 测试球保留在 `src/animal-visual.tsx`。Avatar 定义、局部样式、状态颜色和
基于动画帧的朝向过渡由插件负责；减少动态效果时立即应用朝向，卸载清理动画帧。
角度更新最多每秒 30 次，几何和材质引用保持稳定；发送位使用透明方形视口保留完整猫头与耳朵，不加额外底色；Host 在替换视觉挂载期间隐藏原生按钮背景，卸载恢复。
Avatar 自身交互关闭，只消费授权的位置快照。模型参数更新曾出现旧模块缓存，
本次通过完整加载验证最终定义，尚不宣称模型模块热更新已验证。

角色配置位于 `src/avatar-model.ts`。猫头使用内置几何，透明背景且不再采用
测试球的圆形裁剪，以免切掉耳朵。已撤掉用户否定的颜色滤镜，保留模型原配色；状态值仍投影到插件数据，录音／转写的可见反馈有待重新处理。

鼠标进入下方猫头区域时，通过公开 Avatar 动画解析器播放一次无嘴巴的 Wink；移出恢复，再次进入可重播，朝向跟随继续。减少动态效果时跳过动画。

授权 `drag` 与 `activate` 后，上方猫头可以拎起并左右移动；松手后落回 composer 顶边，保留水平位置。下落中再次抓取从当前位置继续，窗口尺寸改变会限制在可见边界。减少动态效果时立即归位，不跨重载保存位置。

上方头像通过眼睛和整体头部动作表达点击反馈，不依赖耳朵：轻戳时短暂压缩回弹；短时间连点积累打扰程度，逐渐缩头、眯眼，最后停住注视。停止后逐渐舒展。新的点击为当前动作追加小幅冲量，不重播首帧；真正拖拽会取消反馈和累积情绪。拎起上方猫头时显示大小眼的惊讶表情，下落时双眼瞳孔放大，落地恢复；上方不再播放 hover Wink。拖拽与下落表情优先于点击表情。下方猫头维持现有 hover 动画，状态动画尚未选定。命中检测与指针捕获由 Host 通过公开拖拽句柄负责。

拎起时猫头轻微变成水滴形，松手后从当前形状连续恢复；同一条公开受控 Avatar timeline 保留快速松手、再次抓取时的进度。落地时轻微压缩并回弹，减少动态效果时跳过这两种效果。上方定义启用公开 lighting 并将 distance 设为 0：Avatar 1.0.0-rc.8 需要该渲染路径，才能在形变时保留隐式预设猫头的几何。没有修改依赖或复制预设几何，white 配色保持头部和猫耳一致。
