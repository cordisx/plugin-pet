# 宠物系统说明

此页描述正在开发的源码，不代表 v0.1.1 安装包已经包含这些功能。

## 照顾宠物

饱食度、精力和健康范围均为 0–100。新宠物从饱食度 80、精力 100、健康 100 开始。在线每小时饱食度减少 6；低于 20 后先有 60 分钟在线宽限，之后健康每小时减少 4。吃饱时健康每小时恢复 2。清醒时精力每小时减少 8，睡眠时每小时恢复 20；低精力不会单独导致死亡。

宠物系统启用且应用运行时推进照顾计时，关闭应用、系统休眠、持久化暂不可用的时间不补扣。多窗口共享一份存档，只结算尚未推进的在线时间。隐藏宠物仅改变显示；关闭插件才停止其在线照顾。

长期饥饿导致健康归零后，宠物退出 Composer，保留收藏记录。可以在「我的宠物」安葬并移入纪念园，或从「我的宠物」／背包使用一枚重启核心复活。安葬后仍可复活。复活恢复 80 饱食度、80 精力、80 健康，保留名字、皮肤和亲密度，随后可手动安排出场。

食物提供饱食度、精力和亲密度，具体数值以商品卡为准。比特脆脆是日常零食，显存糯米团是补给，满血火锅适合庆祝。永久商品只能获得一次，食物和重启核心按库存消耗。

## 体重与动作

猫、狗、兔子的基础体重分别为 4、8、2 kg。体重变化按各物种的基础值计算：饥饿每在线小时减少基础体重的 1%，饱食度高于 90 的时间每小时增加 0.5%。体重限制在基础体重的 65%–150%，视觉大小限制在默认体型的 85%–118%，并平滑变化。发送按钮保持原有尺寸，通过轻微横向变化表达肥瘦。

拖拽优先于点击和待机；右键菜单打开时对应宠物暂停动作。睡眠第一次点击先唤醒。连续戳动积累短期打扰情绪，停止后恢复；长期亲密度不因被戳烦而扣除。互动奖励有一分钟间隔和每日上限，避免连续点击刷进度。

「减少动态效果」停用滚动、跳跃和大幅形变；静态闭眼休息仍恢复精力。鼠标观察不可用时保留朝向，重新进入后平滑接续。

## 存档与恢复

存档经公开 `ctx.documents` 保存，Host 按本机 profile、来源和插件身份隔离。换窗口、普通重载和同来源升级保留状态；不同来源或 profile 不自动继承，不宣称账号或跨设备同步。

购买扣币、发货、喂食、安葬和复活均作为整份存档的原子事务提交。重复请求有幂等保护，多窗口冲突重试。损坏或未知版本存档拒绝覆盖，不以重置钱包的方式掩盖错误。经济记录保留，移动等高频操作只保存有限的近期记录。

## 开发边界

Pet 负责目录、经济规则、照顾与动画；Avatar 负责模型、配色与花纹；Host 负责权限、原生操作、受控命中区域／菜单和持久化。插件不读取输入正文、原始鼠标事件、音频、原始会话文件或私有 Host 状态。

Token 收入通过独立授权的公开 `ctx.usage` 接口获取。当前初始兑换比例是每 10,000 个新增有效 Token 获得 1 宠物币，余数保留；它不会消耗模型额度。第一次连接只建立基线，不把历史累计直接兑换。钱包与同一用量来源的结算进度一起保存，多窗口、重载和重复通知不能重复发币。

当前覆盖本机可确认的 Codex 输入加输出用量，缓存输入和推理输出已包含在其中，不再次相加；这不是账号账单或跨设备总量。新发现文件的已有内容、来源不明、数据不连续等无法确认的区间不会估算奖励。接口明确标记为部分覆盖，界面显示最近同步时间。暂时不可用时保留钱包和结算进度，恢复后从已确认的累计进度继续同步；欢迎物品和亲密度解锁仍可体验。

收益流水合并为累计记录，来源的结算进度永久保留。购买、喂食等经济记录仍分别保存；存档超过 Host 大小限制时明确拒绝新操作，不会默默丢弃收据或重置余额。

## 宠物管理界面

管理器入口为「宠物」，一级导航包含宠物、商店、背包和设置。钱包及收支从商店余额区域进入，Token 奖励口径保留在钱包页面。

宠物列表展示外观、出场状态、饱食度与亲密度，并可直接选择背包中的食物喂食。点击宠物进入详情，查看完整属性、改名、调整主宠和位置、安排休息或处理安葬与复活。安葬需要再次确认。

商店使用可见分类和隐藏已拥有筛选；商品详情展示效果、适用宠物与解锁要求。皮肤试穿不改变装备，只有已解锁皮肤可以装备。背包只展示已拥有物品，进入详情后选择使用对象。操作结果会在页面内反馈。

返回列表保留当前分类和选中的宠物，并定位到刚才打开的卡片；这些浏览偏好保存在本次插件运行内。页面预览使用中性底色呈现白色外观，不修改宠物本身的颜色，也不增加阴影。Header、返回和面包屑均由 Host 公共导航提供。
